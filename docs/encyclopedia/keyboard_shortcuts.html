Klavye Kısayolları ve Verimli Kullanım

Çalışma hızınızı artırmak için LexiScholar'daki en önemli kısayolların listesi.

Genel Kısayollar

  • Ctrl + S: Projeyi kaydet.
  • Ctrl + Z: Son işlemi geri al.
  • Ctrl + Y: Geri alınan işlemi yinele.
  • F1: Bu ansiklopediyi aç.
  • Ctrl + L: Arayüz düzenini (Dikey/Yatay) değiştir.

Belge ve Kod Ağacı

  • F2: Seçili belgeyi veya kodu yeniden adlandır.
  • Del: Seçili öğeyi sil (Onay istenir).
  • Space: Seçili öğenin etkinliğini (Active/Inactive) değiştir.
  • Ctrl + N: Yeni Kod oluştur.
  • Ctrl + Shift + N: Seçili kodun altına Alt Kod oluştur.

Metin Düzenleyici ve Kodlama

  • Ctrl + B: Kalın yazı (Düzenleme modunda).
  • Ctrl + I: İtalik yazı.
  • Ctrl + U: Altı çizili yazı.
  • Ctrl + Shift + C: Seçili metne aktif kodu hızlıca ata.
  • Ctrl + M: Seçili metne yeni not (Memo) ekle.

Gezinme

  • Alt + 1: Belge Ağacı'na odaklan.
  • Alt + 2: Kod Ağacı'na odaklan.
  • Alt + 3: Metin Editörü'ne odaklan.
  • Ctrl + F: Metin içinde ara.
