OpenRouter API Entegrasyonu

LexiScholar, hibrit yapay zeka özelliklerini (RAG Sohbeti, Semantik Sentez vb.) çalıştırmak için OpenRouter altyapısını kullanır. Bu rehber, akademik analizleriniz için gerekli API anahtarını edinme sürecini açıklar.

Neden OpenRouter?

OpenRouter; Anthropic (Claude), Google (Gemini), OpenAI (GPT) ve Meta (Llama) gibi devlerin modellerine tek bir bakiye ve anahtar ile erişmenizi sağlayan yüksek performanslı bir ağ geçididir. Akademik araştırmalarda model çeşitliliği (Diversity of Opinion) için en ideal çözümdür.

1

Hesap Oluşturma

OpenRouter.ai üzerinden kurumsal veya kişisel e-posta adresinizle bir hesap oluşturun.

OpenRouter Portalı
2

Kredi Yükleme

OpenRouter "Kullandığın Kadar Öde" (Pay-as-you-go) modelini kullanır. 5$ veya 10$ gibi mikro yüklemeler, binlerce sayfalık nitel veri analizi için yeterli olacaktır.

3

API Key Üretimi

Keys menüsünden LexiScholar için özel bir anahtar oluşturun. Anahtar sk-or-v1-... formatında olacaktır.

Güvenlik Uyarısı

API anahtarınız dijital cüzdanınız hükmündedir. Asla başkalarıyla paylaşmayın. LexiScholar, bu anahtarı yerel cihazınızda şifrelenmiş olarak saklar; sunucularımıza asla iletilmez.
